# Mango Leaf Disease Detection using Deep Learning

An AI-powered computer vision application that detects and classifies mango leaf diseases from uploaded images. The project leverages Transfer Learning with MobileNetV2 and TensorFlow to identify multiple mango leaf diseases, including Anthracnose, Bacterial Canker, Powdery Mildew, Sooty Mould, and Healthy leaves.

The system is designed to provide fast, accurate, and user-friendly disease diagnosis through a Streamlit web interface, enabling farmers, researchers, and agricultural professionals to assess plant health with minimal effort.

## Features

* Multi-class mango leaf disease classification
* Transfer Learning using MobileNetV2
* Image preprocessing and augmentation pipeline
* Interactive Streamlit web application
* Real-time disease prediction with confidence scores
* Lightweight and deployable on free cloud platforms

## Technology Stack

* Python
* TensorFlow / Keras
* MobileNetV2
* NumPy
* Pillow
* Streamlit

## Model Performance

The model was trained on a labeled mango leaf disease dataset and achieved strong classification performance across multiple disease categories while maintaining efficient inference speed suitable for web deployment.
